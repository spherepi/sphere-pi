# PiSphere ऐप: फाइलों की सूची

सारी फाइलें एक ही फोल्डर में रहती हैं, कोई सब-फोल्डर नहीं है। GitHub पर इन्हें रिपॉजिटरी में सीधे अपलोड करें।
किसी चीज में बदलाव करना हो तो सिर्फ उसी की फाइल बदलनी होगी।

## मुख्य फाइलें

| फाइल | इसमें क्या है |
|---|---|
| `index.html` | ऐप का मुख्य पेज। यही बाकी सारी फाइलों को लोड करता है। |
| `app.css` | रंग, साइज, डार्क थीम, बटन का रूप। |
| `config.js` | सारे नियम: 1 Pi = 1000 SP, रिवॉर्ड, लिमिट, एडमिन यूजरनेम, भाषाओं की सूची। |
| `logo.png` | लोगो। |
| `promo.mp4` | प्रोमो वीडियो। |
| `_headers` | Cloudflare Pages के सिक्योरिटी हेडर। |

## हर स्क्रीन की अपनी फाइल

| फाइल | इसमें क्या है |
|---|---|
| `promo.js` | ऐप खुलते ही चलने वाला प्रोमो वीडियो। |
| `signin.js` | Pi साइन-इन की स्क्रीन और Pi SDK से लॉगिन। |
| `profile.js` | प्रोफाइल फॉर्म और फोटो अपलोड। |
| `shell.js` | हेडर, नीचे के चार बटन, कॉपीराइट लाइन। |
| `chats.js` | चैट, ग्रुप, चैनल और चैट रूम। |
| `meetings.js` | क्लाउड मीटिंग की स्क्रीन। |
| `feed.js` | पोस्ट फीड। |
| `rewards.js` | Rewards: SP बैलेंस, खरीद, भेजना, पाना, हिसाब। |
| `admin.js` | एडमिन पैनल। |

## साझा हिस्से

| फाइल | इसमें क्या है |
|---|---|
| `core.js` | सेव किया हुआ डाटा, छोटे औजार, आइकन, दबाकर रखने का लॉजिक। |
| `points.js` | SP जोड़ना और घटाना, और रिवॉर्ड के सारे नियम। |
| `ads.js` | लोकल विज्ञापन और हेडर के नीचे चलने वाली पट्टी। |
| `actions.js` | Like, Dislike, Pin, Unpin, Delete। |
| `sheets.js` | नीचे से खुलने वाले पैनल: होल्ड मेनू, प्रोफाइल कार्ड, टिप, भाषा, सेटिंग, क्लेम। |
| `main.js` | सही स्क्रीन दिखाना और ऐप शुरू करना। |

## भाषाएं

हर भाषा की एक फाइल है: `lang-en.js`, `lang-hi.js`, `lang-gu.js`, `lang-mr.js`, `lang-kn.js`, `lang-ta.js`,
`lang-te.js`, `lang-as.js`, `lang-zh.js`, `lang-ja.js`, `lang-id.js`।

नई भाषा जोड़ने के तीन कदम:

1. `lang-en.js` की नकल करके नई फाइल बनाएं, जैसे `lang-bn.js`, और उसमें `PS_I18N.en` की जगह `PS_I18N.bn` लिखें।
2. शब्दों का अनुवाद करें।
3. `index.html` में एक लाइन जोड़ें: `<script src="lang-bn.js"></script>`, और `config.js` की `languages` सूची में `["bn", "বাংলা"]` जोड़ें।

## ध्यान रखें

- `index.html` में फाइलों का क्रम न बदलें। `main.js` सबसे आखिर में रहनी चाहिए।
- सीक्रेट की (Pi API key, Supabase service key, LiveKit secret) इन फाइलों में कभी न डालें।
- यह चरण 1 है: डाटा अभी सिर्फ उसी फोन में सेव होता है। साझा डाटा, असली Pi पेमेंट और वीडियो मीटिंग चरण 2 में जुड़ेंगे।
